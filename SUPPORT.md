# Getting help

Thanks for using **Incarna**! Here's how to get unstuck.

## 1. Read the docs first

Most questions are answered in the [README](README.md) and the [`docs/`](docs/)
folder:

- [`docs/adding-an-agent.md`](docs/adding-an-agent.md) — connect your OpenClaw agents
- [`docs/adding-actions.md`](docs/adding-actions.md) — add agent actions
- [`docs/panels.md`](docs/panels.md) — panels and the Board
- [`docs/security.md`](docs/security.md) — security notes and hardening

## 2. Ask a question

For "how do I…?", ideas, and general discussion, use
[GitHub Discussions](../../discussions). It's the best place to reach
maintainers and other users.

## 3. Report a bug or request a feature

Open a [GitHub Issue](../../issues) using the provided templates. Clear repro
steps, your headset/browser, and logs help a lot.

## Troubleshooting tips

- Open the in-app **🐞 diagnostics panel** to inspect live state.
- Check **`incarna.log`** on the server for detailed request and error output.

## Security

**Do not** report security issues in the public issue tracker. Please follow the
process in [SECURITY.md](SECURITY.md) instead.
