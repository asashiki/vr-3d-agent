# 90–120 Second Demo Script

## 0:00–0:15

Open the same URL in desktop Chrome. Show the clean landing screen and click Desktop Preview. Then open it in Quest Browser and click Enter MR.

## 0:15–0:30

Mira appears beside the World Tray. Grip the tray area and use the thumbstick to show tray scale; explain that the tray avoids fragile whole-room scanning.

## 0:30–0:55

Say or type: “在我面前搭一个治愈系小花园，有一棵树、一张长椅、两盏灯和一些花。” Keep the Agent Trace visible as the structured commands execute and at least five objects appear.

## 0:55–1:15

Say: “把左边的灯移到树旁边，树缩小一点，删掉右边的石头。” Point out that the bench and right lamp remain unchanged.

## 1:15–1:35

Grip/pinch the bench and move it. Say: “保持长椅现在的位置，保存这个场景。” Refresh, then press Restore.

## 1:35–2:00

Show the Inspector, Scene Tool Reference, 30-item CC0 manifest and model license. Disconnect the live provider or switch to Replay and run the demo again to prove the fallback.
